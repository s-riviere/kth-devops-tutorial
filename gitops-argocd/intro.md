# GitOps and Continuous Reconciliation with Argo CD

This is the first functional version of the tutorial.

The goal is simple:

1. Connect Argo CD to a Git repository.
2. Deploy a small Kubernetes application from Git.
3. Introduce configuration drift manually.
4. Let Argo CD restore the desired state.

> The tutorial text is intentionally minimal for now. We will improve the explanations, architecture diagram, and learning outcomes once the scenario works end-to-end.
